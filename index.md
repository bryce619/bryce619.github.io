## Selected Dataset: U.S. Truck-Involved Fatal Crashes (2018–2024)

**Dataset:** [U.S. Truck-Involved Fatal Crashes — GitHub Repository](https://github.com/MarvinBregiosa/vision-zero-fars)

**Source:** National Highway Traffic Safety Administration (NHTSA), Fatality Analysis Reporting System (FARS).

### Dataset Description

I selected the U.S. Truck-Involved Fatal Crashes dataset, which contains approximately 33,900 records of fatal crashes involving medium and heavy commercial trucks throughout the United States from 2018 through 2024.

The data includes information such as the year, state, city, geographic coordinates, and number of fatalities associated with each crash.

### Potential Applications and Value

This dataset could be used to identify crash hotspots, analyze trends over time, and compare fatal truck crashes across different geographic regions.

Using Python and GIS mapping tools, researchers could visualize crash locations and investigate patterns that may help inform transportation planning and road safety improvements.

I find this dataset interesting because it demonstrates how real-world transportation data can be analyzed to better understand and potentially address a public safety problem. I was also drawn to it because it closely aligns with my BDA 594 group project that examines serious and fatal injuries in traffic collisions recorded by the San Diego Police Department between 2015 and 2025.

## Selected Data Science Book: R for Data Science

**Title:** R for Data Science: Import, Tidy, Transform, Visualize, and Model Data

**Authors:** Hadley Wickham and Garrett Grolemund

**Edition:** First Edition (2017)

**Book URL:** [Read R for Data Science Online](https://r4ds.had.co.nz/)

### Book Description

R for Data Science introduces the process of working with data using the R programming language. It covers importing datasets, cleaning and organizing information, transforming data, creating visualizations, and building statistical models.

The book provides practical examples using R and packages such as ggplot2 and dplyr. It also emphasizes organizing analytical workflows and producing reproducible results.

### Why I Selected This Book

I selected this book because I am currently learning R and RStudio in my graduate coursework and want to strengthen my ability to apply programming to real-world data analysis.

The book's practical approach will help me become more comfortable cleaning datasets, creating visualizations, and interpreting results. These skills will be valuable throughout my Master's in Big Data Analytics and my transition into a career in data science.
